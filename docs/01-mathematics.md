# 01 数学基础

数学是 CS 的地基。不是因为考试要考，而是因为后面每一门硬课——算法、图形学、机器学习、密码学、编译原理——本质上都是数学换了一身衣服。你可以不会手算行列式，但不能没有数学直觉：**看到一个问题，能先把它翻译成数学语言，再动手写代码**。这就是数学对 CS 的全部意义。

## 1.1 离散数学：最重要的一门，没有之一

**为什么 CS 需要它**：离散数学就是 CS 的母语。逻辑、集合、图论、组合、数论——数据结构里的树和图、数据库里的关系代数、网络里的路由、算法里的递推和证明，全部长在离散数学上。离散数学没学好，后面每门课都会觉得“概念太多、记不住”，因为你缺的不是记忆力，是语言。

**合格线（毕业合格）**：

- 命题逻辑与谓词逻辑：会写、会读、会用真值表和自然演绎证明简单的命题；理解量词的顺序为什么重要（`∀x∃y` 和 `∃y∀x` 不是一回事）
- 集合、关系、函数：理解等价关系与划分、偏序、函数的单射/满射/双射，并能用它们描述实际问题
- 数学归纳法：能用归纳法证明算法的正确性和递推式的解
- 图论：图、树、二分图、连通性、欧拉路/哈密顿路、着色、最短路——会建模，会把实际问题翻译成图问题
- 组合计数：排列组合、容斥原理、递推关系、生成函数入门
- 初等数论：模运算、欧几里得算法、费马小定理（密码学和哈希的入口）

**优秀线**：会用形式化方法描述一个系统（比如用状态机描述协议）；读得懂算法教材里的证明——比如 CLRS 里归并排序正确性的归纳证明、主定理的证明思路，能说出“这一步为什么成立”；理解可计算性与复杂度类的基本概念（P/NP 是什么、规约是什么意思）。

**常见误区**：

- 把离散数学当成“文科背诵课”，考前背定义、考后全忘。离散数学是练出来的：每一章至少亲手做 20 道证明题。
- 只学逻辑和集合，跳过图论。图论是离散数学里对工程师最有用的部分，跳过它等于白学一半。
- 觉得“数学归纳法就是套模板”。归纳法的难点永远在“归纳假设到底假设了什么”，模板背下来也没用。

**推荐资源**：

- Kenneth H. Rosen《离散数学及其应用》（Discrete Mathematics and Its Applications）——覆盖最全的教材，习题多且分层清晰，读 70% 就够用
- MIT 6.042J（现 6.1200）Mathematics for Computer Science（公开课 + 讲义免费）——更偏 CS 视角，证明风格值得学
- Susanna Epp《离散数学导论》——如果 Rosen 读着吃力，先读这本入门

## 1.2 线性代数：从“会算”到“看得见”

**为什么 CS 需要它**：图形学里没有线性代数寸步难行；机器学习本质上是高维空间里的线性代数加优化；计算机视觉、推荐系统、搜索引擎（PageRank 就是特征向量）全是它。更重要的是，线性代数训练的是一种思维：**把数据看成向量、把变换看成矩阵、把问题看成空间里的几何**。

**合格线（毕业合格）**：

- 向量、矩阵、线性方程组：会解，会判断解的存在唯一性
- 线性相关/无关、基、维数、秩、零空间：理解概念本身，而不只是会算
- 线性变换：理解矩阵就是线性变换，理解“变换前后的空间长什么样”
- 特征值与特征向量：知道它们在说什么（沿着特征向量方向，变换只是缩放），会算，会用
- 内积、正交、最小二乘：理解投影的思想，知道最小二乘为什么是“最优近似”

**优秀线**：奇异值分解（SVD）的几何意义和用途；矩阵分解在推荐系统/降维里的角色；理解“数值稳定性”为什么重要（条件数、病态矩阵）。

**常见误区**：

- 只会算行列式和求逆，不理解几何意义。线性代数的精髓在几何直觉，不在计算。算可以交给计算机，理解不能。
- 学完就忘，因为没有用过。学完立刻找应用：用 NumPy 做一次图像旋转、用 SVD 做一次简单的数据降维，直觉立刻就长出来了。

**推荐资源**：

- Gilbert Strang《线性代数及其应用》（Introduction to Linear Algebra）——几何直觉最强的教材，Strang 的 MIT 公开课（18.06）免费且极好，先看课再读书
- 3Blue1Brown《线性代数的本质》系列视频——建立直觉最快的入口，适合在啃书之前先看一遍
- David C. Lay《线性代数及其应用》——习题更贴近应用，适合配合练习

## 1.3 概率统计：处理不确定性的语言

**为什么 CS 需要它**：机器学习、数据分析、网络协议、分布式系统、算法分析（随机算法、哈希、Bloom filter）全都需要概率思维。更根本的是，真实世界的数据全是带噪声的，**没有概率直觉的工程师，会把随机波动当成规律、把相关当成因果**。

**合格线（毕业合格）**：

- 概率基础：条件概率、贝叶斯定理、全概率公式——会算，会用贝叶斯定理更新信念
- 随机变量与分布：二项、泊松、正态、指数分布的含义和适用场景；期望、方差、协方差
- 大数定律与中心极限定理：知道它们在说什么（为什么“平均”会稳定、为什么正态分布到处都是）
- 统计推断：点估计、区间估计、假设检验的基本逻辑；p 值的正确理解（以及它最常见的误读）
- 信息论入门：熵、交叉熵、KL 散度——知道它们度量的是什么

**优秀线**：最大似然估计与贝叶斯推断的区别；蒙特卡洛方法的基本思想；能看懂一篇机器学习论文里的实验统计部分（置信区间、显著性）。

**常见误区**：

- 混淆相关与因果。这是最常见、代价最大的错误，统计学的第一课就是分清它。
- 迷信 p 值。p < 0.05 不是“结论正确”的证明，只是在零假设下看到这么极端数据的概率。
- 只会套公式算概率，不会建模。概率题的关键永远是“样本空间到底是什么”，公式是最后一步。

**推荐资源**：

- Sheldon Ross《概率论基础教程》（A First Course in Probability）——例子极多，适合自学
- 《概率论与数理统计》（茆诗松等）——国内教材里体系较完整的一本
- MIT 6.041（现 6.4310）Probabilistic Systems Analysis（公开课）——偏工程应用，讲得清楚
- David MacKay《信息论、推理与学习算法》（Information Theory, Inference, and Learning Algorithms）——免费，信息论部分写得极好

## 1.4 微积分与数值方法：够用就好，但“够用”要真够

**为什么 CS 需要它**：优化（梯度下降就是微积分）、图形学（微分几何）、数值计算、信号处理。相对前三门，微积分对一般 CS 工作的直接需求较浅，但它是“读得懂论文、跟得上优化推导”的门票。

**合格线（毕业合格）**：

- 一元微积分：导数、积分、泰勒展开——会算，会用泰勒展开做近似分析
- 多元微积分：偏导数、梯度、链式法则、拉格朗日乘子——理解梯度就是“最陡上升方向”
- 数值方法入门：浮点数的表示与误差（为什么 `0.1 + 0.2 != 0.3`）、数值稳定性、基本的数值微分/积分思想

**优秀线**：理解梯度下降、牛顿法的收敛性；知道病态问题与条件数；会分析一个数值算法的误差来源。

**常见误区**：

- 在微积分上投入过多时间。它对 CS 的边际收益远低于离散数学和线性代数，够用即可，省下的时间去补那两门。
- 死记求导积分的技巧。CS 需要的是“梯度、优化、近似”这三个概念，不是手算积分的熟练度。

**推荐资源**：

- James Stewart《微积分》（Calculus）——体系完整，当工具书查即可，不必通读
- MIT 18.01 单变量微积分（公开课）——够用
- 数值方法部分：看 CSAPP 第 2 章的浮点数部分，或《数值分析》任意一本入门教材的浮点数章节即可

## 自测题

1. **归纳证明**：用数学归纳法证明 `1 + 2 + … + n = n(n+1)/2`，写出基础步、归纳假设、归纳步三部分，并用一句话说清“归纳假设到底假设了什么”。验证：找一个人（或对照教材）检查三部分是否齐全、归纳步是否真的用到了假设。
2. **建模**：一门课有先修关系（A 必须在 B 之前修），请把“排课”翻译成图问题：顶点和边分别是什么？用什么算法得到一个合法的修课顺序？验证：能说出“拓扑排序”，并讲清有环时意味着什么。
3. **浮点数**：写一小段程序打印 `0.1 + 0.2` 的二进制表示，并解释为什么它不等于 `0.3`。验证：程序跑通，能说出 IEEE 754 双精度尾数 52 位带来的误差来源。

## 本章总结

| 分支 | 优先级 | 合格的标志 |
|---|---|---|
| 离散数学 | 最高 | 能用逻辑和图论给实际问题建模，能写归纳证明 |
| 线性代数 | 高 | 理解变换的几何意义，知道特征值在说什么 |
| 概率统计 | 高 | 会用贝叶斯更新信念，分得清相关与因果 |
| 微积分/数值 | 中 | 理解梯度和优化，会分析浮点误差 |

**一句话**：数学不是 CS 的“前置课”，而是 CS 的“工作语言”。合格的标准不是“考过”，而是“在后面的课里用得上”。
