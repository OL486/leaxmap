# 08 学习路径

前面七章讲了“需要什么”，这一章讲“按什么顺序拿”。路线图分两种：一种是按部就班的四年路线，一种是时间不够时的压缩路线。两种都写出来，你按自己的情况选。

## 8.1 大一：打地基，别急着选方向

**目标**：学会编程、养成工程习惯、把数学地基打好。

| 事项 | 具体内容 | 产出 |
|---|---|---|
| 编程入门 | 精通一门语言（建议 Python 或 C），写够 5000 行代码 | 能独立写中等复杂度程序 |
| 数学 | 离散数学、线性代数同步学 | 能用逻辑和图论建模简单问题 |
| 工具 | Git、命令行、编辑器配好 | 自己的项目有版本管理 |
| 习惯 | 开始写笔记、开始读技术文章 | 笔记系统跑起来 |
| 项目 | 做 1–2 个小项目（待办清单、简单爬虫、命令行工具） | GitHub 上有能跑的项目 |

**不要做的事**：不要追框架、不要报一堆培训班、不要同时学三门语言。大一最宝贵的是“把一件事做深”的耐心。

**里程碑**：大一结束时，你应该能不看教程、独立写出一个 1000 行左右的完整程序，并讲清它的结构。

## 8.2 大二：系统课 + 算法，CS 的硬核年

**目标**：数据结构与算法、计算机系统课全部拿下，开始有“系统思维”。

| 事项 | 具体内容 | 产出 |
|---|---|---|
| 数据结构与算法 | 必会清单全部过一遍，开始按类型刷题 | 刷题 100 道以上 |
| 计算机系统 | 组成原理、操作系统、计算机网络 | 能讲清程序从代码到执行的完整链条 |
| 数据库 | SQL、事务、索引 | 能设计一个合理的数据库 |
| 编译原理 | 词法、语法、语义入门 | （可选）开始写一个小语言 |
| 项目 | 做一个完整项目（带数据库的 Web 应用 / 小游戏 / 工具软件） | 一个能讲 10 分钟的项目 |
| 开源 | 给开源项目提第一个 PR（修文档、补测试都行） | 走完一次完整 PR 流程 |

**不要做的事**：不要为了刷题放弃系统课。系统课是大二的正事，刷题是副业。本末倒置的人，大三会发现自己“会做题、不会做系统”。

**里程碑**：大二结束时，你应该能讲清“一个 HTTP 请求从浏览器发出到数据库返回，中间经过了哪些层次、每层做了什么”。

## 8.3 大三：定方向，做深度

**目标**：选定一个方向，做深；同时把软件工程能力补齐。

| 事项 | 具体内容 | 产出 |
|---|---|---|
| 定方向 | 从 06 章里选一个方向，投入一个学期验证 | 方向相关的 2–3 个项目 |
| 深度项目 | 做一个能讲 20 分钟的项目（最好是“从零实现”类：小语言、KV 存储、HTTP 服务器） | 简历上最硬的一个项目 |
| 软件工程 | 设计模式、架构、CI、代码评审 | 项目有 CI、有测试、有文档 |
| 实习 | 找一份实习（暑期或学期中兼职） | 一段真实的工程经历 |
| 面试准备 | 系统刷题到 200–300 道，模拟面试 | 能通过大厂技术面试 |
| 数学补强 | 按方向补数学（AI 补概率和优化、图形学补线代和微积分） | 方向所需的数学过关 |

**不要做的事**：不要同时追三个方向。选一个，做深，做到能讲清这个方向的经典问题和 trade-off。

**里程碑**：大三结束时，你应该有一个“能讲 20 分钟、每个设计决策都能说出为什么”的项目，和一段实习经历。

## 8.4 大四：收尾与选择

**目标**：把前三年的积累变成选择权——就业、深造、创业，怎么选都有底气。

| 事项 | 具体内容 | 产出 |
|---|---|---|
| 毕业设计 | 选一个有挑战的题目，认真做 | 一份拿得出手的毕设 |
| 求职/深造 | 按目标准备（面试、考研、申请） | 拿到满意的 offer 或录取 |
| 复盘 | 对着 checklist 重新自评一遍，补最后的短板 | 知道自己还缺什么 |
| 输出 | 写几篇技术博客，整理自己的项目和笔记 | 公开的、可验证的积累 |
| 交接 | 把做过的项目整理好，写清楚文档，留给后来人 | 别人能接手你的项目 |

**不要做的事**：不要大四才开始准备求职。求职准备是大三的事，大四是收获的时候。

**里程碑**：毕业时，你应该能对着这份地图说：“毕业合格的每一项我都做到了，优秀的大部分做到了，有一个方向我做到了顶尖。”

## 8.5 压缩路径：自学 / 转码 / 补基础

如果你不是科班出身，或者时间只有一年左右，按这条压缩路径走。原则是：**砍掉“考试要考但工作不用的”，保住“地基”**。

| 阶段（约 2–3 个月） | 内容 | 产出 |
|---|---|---|
| 第 1 阶段：编程 | 一门语言精通 + 数据结构与算法基础 + 刷题 100 道 | 能写代码、能通过面试算法关 |
| 第 2 阶段：系统 | 操作系统 + 计算机网络 + 数据库（只学核心概念，不做全文背诵） | 能讲清系统层面的问题 |
| 第 3 阶段：工程 | Git + 一个完整项目 + CI/测试/文档 | 一个能讲 10 分钟的项目 |
| 第 4 阶段：方向 | 选一个方向，做 2 个项目，准备面试 | 拿到 offer |

**压缩路径的取舍**：

- 砍掉：编译原理的深入部分、数学的证明细节、冷门方向。
- 保住：编程、数据结构与算法、操作系统、网络、数据库、一个完整项目。**这六样一件都不能砍**，砍了就是空中楼阁。
- 注意：压缩路径只能让你“达到毕业合格”，到“优秀”需要之后在工作中继续补。不要以为一年就能走完四年的路。

## 8.6 每年都该做的三件事

不管在哪一年，这三件事每年都要做：

1. **做一个完整项目**。一年至少一个，从 0 到 1，能跑、能讲、能复盘。
2. **读一个开源项目的源码**。一年至少一个，读完能画出结构图。
3. **写几篇技术文章**。一年至少 3 篇，把学到的东西讲出来——讲不出来就是没真懂。

## 本章总结

| 阶段 | 关键词 | 里程碑 |
|---|---|---|
| 大一 | 编程、数学、习惯 | 独立写出 1000 行程序 |
| 大二 | 算法、系统 | 讲清一次 HTTP 请求的完整链条 |
| 大三 | 方向、深度、实习 | 一个能讲 20 分钟的项目 + 实习 |
| 大四 | 收尾、选择 | 毕业合格全做到，优秀大部分做到 |
| 压缩路径 | 只保地基，砍掉枝叶 | 一年达到毕业合格 |

**一句话**：路线图不是任务清单，是节奏感。大一别急、大二别偏、大三别散、大四别慌。
